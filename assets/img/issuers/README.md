# Issuer mark sources

Monochrome issuer marks from Simple Icons 16.35.0. The package archive was checked against its npm SHA-512 integrity value. These are issuer marks, not certification badges.

| File | Brand source |
| --- | --- |
| `googlecloud.svg` | https://cloud.google.com |
| `google.svg` | https://partnermarketinghub.withgoogle.com |
| `linuxfoundation.svg` | https://www.linuxfoundation.org/brand-guidelines |
| `cncf.svg` | https://github.com/cncf/artwork/blob/d2ed716cc0769e6c65d2e58f9a503fca02b60a56/examples/other.md#cncf-logos |
| `isc2.svg` | https://www.isc2.org |
| `cisco.svg` | https://www.cisco.com |
| `coursera.svg` | https://about.coursera.org/press |

`microsoft.svg` retains the existing four-square Microsoft mark. Brand reference: https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks

Issuers without sourced artwork use plain text abbreviations. Matching public credential badges take precedence over issuer marks; see `../badges/README.md` for their provenance.
