# Public credential badges

These unmodified PNGs were retrieved over HTTPS from images.credly.com and matched to the public badges on https://www.credly.com/users/tay-kai-keng/badges/credly. The original twelve records were checked on 15 October 2026; the Cisco Cybersecurity Essentials course badge was added on 16 October 2026. `sources.json` records individual verification pages, image sources, issue/expiry dates, check dates, and SHA-256 digests.

The artwork belongs to the respective issuers and is displayed to identify the holder’s credentials, not as an endorsement of this site. The verification link on each matching card leads to the individual public badge. Other credentials retain issuer marks or text labels.

To refresh a credential, check its individual public page, replace the matching local image only if needed, and update the dates in `assets/js/portfolio-data.js` and this source record. Do not infer validity from the badge artwork alone.
