BinImg2Vec: Augmenting Malware Binary Image Classification with Data2Vec

Authors: Kai Keng TAY, Lee Joon Sern (Lead Data Scientist, Ensign Labs), Chua Zong Fu (VP, Ensign Consulting)

Traditional signature detection falls short against obfuscated, polymorphic malware. In this research, we propose a novel self-supervised framework: converting unexecuted raw binary executable files into 2D grayscale pixel representations, then using Data2Vec (Vision Transformer) to learn deep latent contextual representations across the binary landscape.

> Zero Feature Engineering: Bypasses tedious manual assembly disassembly and heuristics by operating directly on normalized byte matrices.
> Self-Supervised Pre-training: Employs multi-modal masked prediction via Data2Vec, achieving high representation fidelity with limited labeled malware samples.
> High-Accuracy Generalization: Outperforms conventional Convolutional Neural Networks (CNNs) across obfuscated ransomware and Trojan families.
